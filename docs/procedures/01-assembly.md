# 절차 01 — 조립

2 kg 급 쿼드 조립. **위에서 아래로 순서대로** 진행한다.
각 항목은 다음 항목의 전제다. 건너뛰면 뒤에서 되돌아와야 한다.

작성 2026-09-14. 🔶 **아직 한 항목도 수행되지 않았다.**

---

## 🔴 시작 전에 — 아직 답이 없는 것

아래가 확정되기 전에는 조립을 시작할 수 없다.

- 🔴 **프레임 모델명·휠베이스·실측 중량** — 프롭 사이즈가 여기 묶인다
- 🔴 **프롭 사이즈·피치** — [계산서 §7](../design/01-thrust-weight.md)
- 🔴 **5 V 공급원** — ESC 가 No BEC 다 (D 항)
- 🟠 **스택 결정** — ArduCopter 유지냐 PX4 전환이냐 ([FC 문서](../../components/fc/pixhawk-2.4.8/README.md))

---

## A. 부품 검수 · 실측

전부 저울에 올리고 [중량 예산표](../design/01-thrust-weight.md#6-중량-예산--2-kg-를-어떻게-나눌-것인가)를 채운다.

- [ ] 모터 4개 — 중량, 축경, 마운트 홀 피치, 손으로 돌려 걸림·소음 확인
- [ ] 모터 4개 상간 저항 측정 — 4개가 서로 비슷한가 (불량 선별)
- [ ] ESC 4개 — 중량, 입출력 선 규격(AWG), 외관 손상
- [ ] FC — 중량, 핀 헤더 상태, **로그 03 `Crash` 이력이 있으므로 외관 정밀 확인**
- [ ] 프레임 — 중량, 휠베이스 실측, 암 균열·유격
- [ ] 프롭 — 사이즈·피치·재질·중량, 균열
- [ ] 배터리 4S 2900 — 중량, 셀 전압 균형, 부풂 여부
- [ ] GPS·수신기·PM·부저·안전스위치 — 실물 존재 확인, 중량

⚠️ **부풀었거나 셀 전압이 0.1 V 이상 벌어진 리포는 쓰지 않는다.**

---

## B. 프레임 조립

- [ ] 암 4개 체결 — **나사에 중강도 록타이트(파랑)**
- [ ] 상·하판 체결
- [ ] 랜딩기어 부착
- [ ] 🔴 **프롭 간섭 확인** — 휠베이스 ≥ 프롭직경 × √2 + 여유
- [ ] 암 방향 표시 — 전방을 물리적으로 표시한다 (테이프·도색)

---

## C. 모터 장착

- [ ] 모터 4개 암에 체결 — **나사 길이 확인. 너무 길면 권선을 찌른다**
- [ ] 록타이트 도포
- [ ] 모터 4개 수평 확인 — 틀어지면 요(yaw) 드리프트가 생긴다
- [ ] 선을 암을 따라 정리, 프롭에 닿지 않게

---

## D. 🔴 전원 계통 — ESC 가 No BEC 다

**여기가 이 기체의 설계 분기점이다.**

- [ ] 5 V 공급원 확정
  - [ ] 전원모듈(PM) 5 V 출력 사용 → PM 실물·정격 확인 (대개 5.3 V / 2.25 A)
  - [ ] 또는 별도 UBEC 추가 → 5 V / 3 A 이상
- [ ] 배전(PDB) 방식 확정 — 프레임 일체형 PDB 인가, 별도 보드인가, 하네스인가
- [ ] 메인 전원선 규격 확인 — 풀스로틀 25 A 를 견디는가 (14 AWG 이상 권장)
- [ ] 배터리 커넥터 — XT60 이 25 A 에 적합
- [ ] 🔴 **극성 확인** — 역결선하면 FC·ESC 가 즉사한다
- [ ] 안티스파크 대책 (선택)

📋 **전원을 넣기 전, 멀티미터로 +/- 단락 여부를 반드시 측정한다.**

---

## E. ESC 장착 · 배선

- [ ] ESC 4개 암 또는 중앙판에 고정 — **방열 고려, 열선 위에 덮지 않기**
- [ ] ESC 전원선을 PDB 에 납땜 — **극성 재확인**
- [ ] 납땜부 수축튜브 처리
- [ ] 신호선을 FC 출력 1~4 에 연결

출력 배치 (ArduCopter 쿼드 X, [FC 문서](../../components/fc/pixhawk-2.4.8/README.md) 확인값):

| FC 출력 | 모터 | 위치 | 회전 |
|---|---|---|---|
| 1 | Motor1 | 우전 | CCW |
| 2 | Motor2 | 좌후 | CCW |
| 3 | Motor3 | 좌전 | CW |
| 4 | Motor4 | 우후 | CW |

---

## F. 🔴 모터 회전 방향 확정

**프롭을 빼고** 진행한다.

- [ ] 프롭 전부 분리 확인
- [ ] FC 모터 테스트로 1번부터 순서대로 회전
- [ ] 각 모터의 회전 방향이 위 표와 맞는지 확인
- [ ] 틀린 모터는 **3상 중 두 선을 바꿔** 방향 반전
- [ ] 확정 후 각 암에 회전 방향을 **물리적으로 표시**

⚠️ 회전 방향이 틀리면 이륙 즉시 뒤집힌다. 여기서 반드시 잡는다.

---

## G. FC 장착

- [ ] 🔴 **방진 마운트** 사용 — MPU6000 은 진동에 약하다. 양면 폼테이프 또는 전용 댐퍼
- [ ] FC 전방 화살표를 기체 전방에 정확히 일치
- [ ] 케이블이 FC 를 당기지 않게 여유 확보 (당기면 진동이 전달된다)
- [ ] SD 카드 삽입 확인

---

## H. 주변장치

- [ ] GPS — **마스트로 띄운다.** 전원선·ESC 에서 최대한 멀리 (자기간섭)
- [ ] GPS 전방 화살표 정렬
- [ ] 수신기 — 안테나가 카본에 닿지 않게, 2개면 직교 배치
- [ ] 텔레메트리 (있으면)
- [ ] 부저 · 안전스위치 — `BRD_SAFETYENABLE=1` 이므로 **안전스위치가 없으면 ARM 이 안 된다**
- [ ] 배터리 마운트 — 벨크로·스트랩, 무게중심 조정 여유 확보

---

## I. 최종 점검 (프롭 장착 전)

- [ ] 모든 나사 체결 재확인
- [ ] 배선이 프롭 회전면에 들어가지 않는가
- [ ] 무게중심(CG) — 기체 중심에 오는가. 배터리 위치로 조정
- [ ] 총중량 실측 → [계산서 §6](../design/01-thrust-weight.md) 갱신
- [ ] 🔴 **총중량이 2 kg 을 넘는가?** 넘으면 계산서로 돌아가 재검토

# 절차 03 — 지상 시험

첫 비행 전 마지막 관문. **여기서 설계 계산의 추정값을 실측으로 바꾼다.**

작성 2026-09-14. 🔶 **아직 수행되지 않았다.**

> 전제: [절차 02 FC 셋업](02-fc-setup.md) 완료.

---

## 🔴 안전 원칙 — 예외 없다

- **프롭이 달린 상태에서 사람이 기체 회전면 안에 들어가지 않는다.** 14인치 프롭은 손가락을 자른다.
- 프롭을 다는 순간부터 **기체는 무장된 무기**로 취급한다.
- 시험 중에는 **송신기를 손에서 놓지 않는다.**
- 🔴 **비상 정지 스위치 위치를 몸이 기억할 때까지** 프롭을 달지 않는다.
- 기체를 **바닥에 고정**하거나 무거운 것에 묶고 시험한다.
- 보안경 착용.

---

## A. 프롭 없이 — 출력 확인

### 🔴 2026-09-14 미해결 문제 — 여기부터 풀어야 한다

**증상:** MAIN4 모터가 **개별 테스트로는 돌지만, QGC 의 All(4개 동시)에서는 안 돈다.**

**이미 확인된 것:**
- ✅ FC 신호 출력은 정상 — 개별·순차 전체 모두 MAIN4 에 1150 출력
- → **FC 설정 문제가 아니다.** ESC·전원·모터 구간의 문제다

**확인할 순서:**

- [ ] **신호선만 다른 포트로 교체** — 가장 확실한 진단
  - 증상이 **따라가면** → ESC 불량
  - 증상이 **MAIN4 에 남으면** → 배선·전원 분배 문제
- [ ] **4개 동시 기동하며 전압 관찰** — 순간 전압강하가 실제로 일어나는가
  - 4개 동시 기동 전류 → 강하 → 가장 취약한 ESC 가 기동 실패, 라는 가설
- [ ] 그 ESC 의 **전원 납땜** 육안·멀티미터 확인 (접촉저항)
- [ ] ESC 캘리브레이션 후 재시험 — 4개 스로틀 하한이 제각각일 수 있다

🔶 **전류 측정값이 이상하다.** 15 % 스로틀에서 총 0.15~0.19 A 만 나왔다.
3508 모터 4개면 훨씬 커야 한다. 모터가 실제로 안 돌았거나,
`BATT_AMP_PERVLT=18.0` 보정이 틀렸다. **D항 추력시험 전에 반드시 규명할 것.**

### 기본 확인

- [ ] 프롭 전부 분리 확인 (눈으로 4개 다)
- [ ] 배터리 연결, 안전스위치 해제
- [ ] ARM
- [ ] 스로틀 최소에서 4개 모터가 **같은 속도로** 도는가 (`MOT_SPIN_ARM` 동작)
- [ ] 스로틀을 천천히 올려 4개가 **고르게** 증속하는가
- [ ] 이상 소음·진동·발열 없는가
- [ ] DISARM
- [ ] 🔴 모터·ESC 손으로 만져 온도 확인 — **뜨거우면 중단하고 원인부터**

### ⚠️ 모터 테스트 A/B/C/D 는 MAIN 번호가 아니다

위치는 2026-09-16 실측값 (09-14 에는 표준 배치를 가정한 추정치가 잘못 적혀 있었다).

| 테스트 | 실제 출력 | 위치 | 회전 |
|---|---|---|---|
| A | **MAIN1** | 우전 | CCW |
| **B** | **MAIN4** | 좌전 | CW |
| C | **MAIN2** | 우후 | CW |
| D | **MAIN3** | 좌후 | CCW |

"몇 번째가 안 돈다"로 판단하면 포트를 잘못 짚는다.

## A-2. 🔴 ESC 캘리브레이션

**전제:** 프롭 전부 분리. **송신기 바인딩 완료** (스로틀 입력이 필수다).

🔴 2026-09-14 현재 **바인딩이 안 돼 있어 수행 불가**.

### 절차 (ArduCopter)

- [ ] 🔴 프롭 전부 분리 확인
- [ ] 기체 고정, 사람 이탈
- [ ] `ESC_CALIBRATION = 3` 설정
- [ ] 재부팅
- [ ] 배터리 연결 → FC 가 스로틀 최대를 ESC 에 전달 → **ESC 비프음**
- [ ] 송신기 스로틀을 **최저로** → ESC 비프음 → 확정
- [ ] 배터리 분리 후 재연결, 4개가 동일하게 반응하는지 확인
- [ ] [FC_CHANGELOG](../../FC_CHANGELOG.md) 기록

### 🔴 주의 — 의도치 않은 캘리브레이션 모드 진입

2026-09-14 에 실제로 겪었다. **재부팅만 했는데** 이 메시지가 떴다:

```
ESC calibration: Auto calibration
ESC calibration: Push safety switch
```

`ESC_CALIBRATION` 파라미터는 **`0` 그대로**였다. 휘발성 모드다.
ArduCopter 는 **부팅 시 스로틀이 최대로 읽히면 자동으로** 진입한다.
수신기가 유효 신호를 못 주는 상태였던 것이 원인이었다.

- 🔴 **프롭이 달린 상태에서 이 모드에 들어간 뒤 안전스위치를 누르면 모터가 돈다**
- **탈출:** 안전스위치를 누르지 말고 **전원을 껐다 켠다**
- **예방:** 재부팅 전 스로틀 입력이 정상인지 확인한다

### ⚠️ ESC 저전압 컷오프

- [ ] 🔴 **ESC 자체의 저전압 컷오프를 끄거나 최저로 낮춘다**
- 배터리 보호는 **FC failsafe** 가 담당해야 한다.
  ESC 가 독자적으로 모터를 끄면 비행 중 추락한다
- ⚠️ ArduCopter 3.6.12 에는 `SERVO_BLH_*` 가 **없다** → **FC 경유로 ESC 설정 불가**.
  BLHeliSuite + USB 링커를 신호선에 직접 물리거나, 프로그래밍 카드를 써야 한다

## B. 프롭 없이 — 자세 반응

- [ ] ARM, 스로틀 살짝
- [ ] 기체를 손으로 기울인다 → **반대쪽 모터가 증속**하는가
  - 앞으로 기울임 → 앞 모터 증속 (복원하려는 방향)
  - 방향이 반대면 🔴 **모터 배치나 FC 방향이 틀렸다.** 조립으로 돌아간다
- [ ] 요(yaw) 로 비틀면 대각 모터쌍이 반응하는가
- [ ] DISARM

---

## C. 🔴 프롭 장착

- [ ] 회전 방향 재확인 — [조립 F 항](01-assembly.md)의 표시와 대조
- [ ] CW 프롭은 CW 모터에, CCW 는 CCW 에
- [ ] 프롭 너트 규정 토크로 체결
- [ ] 프롭 위아래 방향 확인 (앞전이 회전 방향을 향하게)
- [ ] 손으로 돌려 간섭 없는가
- [ ] 🔴 **기체를 바닥에 고정한다**

---

## D. 추력 시험 — 설계 계산을 검증한다

**이것이 이 절차의 핵심이다.** [계산서](../design/01-thrust-weight.md)의
모든 숫자는 T-Motor 데이터시트 추정치다. 여기서 실측으로 대체한다.

준비물: 저울(기체를 올릴 수 있는 것), 전류계(또는 FC 로그), 고정 수단.

- [ ] 기체를 저울 위에 뒤집어 고정 — 또는 아래로 당기는 힘을 측정하는 구성
- [ ] 스로틀 25 % → 추력·전류·전압 기록
- [ ] 스로틀 50 % → 기록
- [ ] 스로틀 75 % → 기록
- [ ] 스로틀 100 % → **짧게(3초 이내)** 기록
- [ ] DISARM, 모터 온도 확인

### 기록표

| 스로틀 | 총추력(g) | 총전류(A) | 전압(V) | 전력(W) | 효율(g/W) |
|---|---|---|---|---|---|
| 25 % | | | | | |
| 50 % | | | | | |
| 75 % | | | | | |
| 100 % | | | | | |

### 판정

- [ ] **최대 총추력 ÷ 총중량 ≥ 2.0** 인가 (TWR)
  - 🔴 **1.5 미만이면 비행 금지.** 기동 여유가 없다
  - ⚠️ 1.5~2.0 이면 제한 비행만
- [ ] 예상 호버 스로틀 = 총중량 ÷ 최대추력 → **40~60 % 범위인가**
  - 🔴 30 % 미만: 오버파워. 프롭을 줄인다
  - 🔴 70 % 초과: 언더파워. 기체를 줄이거나 프롭을 키운다
- [ ] 최대 전류가 ESC 30 A, 배터리 58 A 안에 드는가
- [ ] 🔴 [계산서](../design/01-thrust-weight.md)를 **실측값으로 갱신**한다

## E. 진동 확인

MPU6000 은 진동에 약하다. 여기서 걸러야 한다.

- [ ] 스로틀 50 % 로 30초 유지하며 로그 기록
- [ ] 로그의 `VIBE` 확인
  - ✅ 진동 X/Y/Z **30 m/s² 미만**
  - ⚠️ 30~60: 개선 권장
  - 🔴 **60 이상: 비행 금지.** EKF 가 무너진다
- [ ] `Clip` 카운트가 증가하는가 → 증가하면 🔴 중단
- [ ] 프롭 밸런싱, 방진 마운트 재점검

---

## F. 배터리 · Failsafe 확인

- [ ] 호버 스로틀 부근에서 전압 새그 측정 — 몇 V 까지 떨어지는가
- [ ] 🔴 **그 전압이 `BATT_LOW_VOLT`(14.0 V) 위에 있는가**
      → 아래면 [셋업 G 항](02-fc-setup.md)으로 돌아가 임계를 다시 잡는다
- [ ] RC failsafe — 송신기를 끄면 설정대로 동작하는가 (프롭 달린 상태, 기체 고정)
- [ ] 🔴 **비상 정지 스위치가 실제로 모터를 즉시 멈추는가** — 반드시 확인

---

## G. GO / NO-GO 판정

전부 ✅ 여야 첫 비행으로 간다. 하나라도 🔴 면 중단.

- [ ] TWR ≥ 2.0
- [ ] 호버 스로틀 예상 40~60 %
- [ ] 진동 < 30 m/s², Clip 없음
- [ ] 모터·ESC 발열 정상
- [ ] 자세 반응 방향 정상
- [ ] 배터리 failsafe 임계 적정
- [ ] 비상 정지 동작 확인
- [ ] GPS fix 양호 (야외)
- [ ] 나침반 오차 경고 없음
- [ ] 총중량 ≤ 2 kg
- [ ] 모든 나사 체결 확인

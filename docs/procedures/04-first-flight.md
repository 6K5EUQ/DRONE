# 절차 04 — 첫 비행

**단계별로 확장한다.** 한 단계를 통과해야 다음으로 간다.
문제가 보이면 그 자리에서 착륙한다. "조금만 더" 는 없다.

작성 2026-09-14. 🔶 **아직 수행되지 않았다.**

> 전제: [절차 03 지상 시험](03-ground-test.md) **GO** 판정.

---

## 🔴 출발 전

- [ ] 지상 시험 GO 판정 확인
- [ ] 🔴 **비행 장소가 합법인가** — 관제권·비행금지구역 확인
- [ ] 🔴 **기체 중량이 2 kg 이하인가** — 초과 시 신고·자격 요건이 달라진다
- [ ] 날씨 — **풍속 3 m/s 이하**. 첫 비행에 바람은 변수만 늘린다
- [ ] 장소 — 개활지, 사람·건물·전선에서 30 m 이상
- [ ] 배터리 만충, 송신기 충전
- [ ] 소화기 또는 모래 (리포 화재 대비)
- [ ] 관찰자 1명 — 혼자 하지 않는다

---

## A. 현장 준비

- [ ] 기체 육안 점검 — 나사, 프롭, 배선
- [ ] 프롭 체결 재확인
- [ ] 송신기 먼저 켠다 → 그 다음 기체
- [ ] GPS fix 대기 — 🔴 **위성 10개 이상, HDOP 1.5 이하**
- [ ] 나침반 경고 없는가
- [ ] 배터리 전압 정상
- [ ] 비행 모드 스위치 위치 = **STABILIZE**
- [ ] 비상 정지 스위치 위치를 손으로 확인
- [ ] 사람 전원 기체에서 10 m 이상 이탈

---

## 1단계 — 지면 이탈 (고도 0.5 m, 10초)

모드: **STABILIZE**

- [ ] ARM
- [ ] 스로틀을 천천히 올려 스키드가 막 뜨는 지점까지
- [ ] 🔴 **기체가 한쪽으로 기울거나 돌면 즉시 스로틀 내린다**
- [ ] 0.5 m 에서 10초 유지
- [ ] 착륙, DISARM

**확인:** 드리프트 방향 · 요 회전 · 이상 소음 · 호버 스로틀 대략값

🔴 **기체가 뒤집히려 하면 → 모터 배치가 틀렸다. 즉시 중단.**

---

## 2단계 — 호버 (고도 1~2 m, 30초)

모드: **STABILIZE**

- [ ] 1~2 m 로 상승
- [ ] 30초 유지, 최소한의 스틱 입력으로 위치 유지
- [ ] 착륙, DISARM
- [ ] 🔴 모터·ESC 온도 확인

**확인:** 호버 스로틀 % · 자세 안정성 · 진동(소리) · 전류

---

## 3단계 — ALT_HOLD

- [ ] 이륙 후 **ALT_HOLD** 로 전환
- [ ] 고도가 유지되는가 — 오르내림이 심하면 🔴 착륙
- [ ] 상승·하강 스틱 반응 확인
- [ ] 30초 유지 후 착륙

**확인:** 고도 유지 품질. 진동이 크면 기압계·EKF 가 흔들린다

---

## 4단계 — 자세 · 기동 (고도 3 m)

모드: **STABILIZE** 또는 **ALT_HOLD**

- [ ] 전후 이동 5 m, 복귀
- [ ] 좌우 이동 5 m, 복귀
- [ ] 요 90° 회전 ×4 (제자리 한 바퀴)
- [ ] 각 축의 반응이 대칭인가
- [ ] 착륙

**확인:** 반응 지연 · 오버슈트 · 진동 발생 여부 → PID 조정 필요성

---

## 5단계 — LOITER (GPS 검증)

🔴 **1~4단계가 전부 정상일 때만.**

- [ ] 이륙 후 **LOITER** 전환
- [ ] 🔴 **기체가 제자리를 유지하는가** — 흘러가면 즉시 STABILIZE 로 복귀
- [ ] 30초 유지
- [ ] 천천히 이동시켜 보고, 스틱을 놓으면 멈추는가
- [ ] 착륙

**확인:** GPS 위치 유지 품질 · 나침반 정확도 (돌면서 흘러가면 나침반 문제)

---

## 6단계 — RTL (선택)

🔴 **5단계 통과 후, 충분한 공간에서만.**

- [ ] 20 m 정도 떨어진 위치에서 **RTL** 작동
- [ ] `RTL_ALT`(15 m)까지 상승하는가
- [ ] 홈으로 복귀하는가
- [ ] 착륙까지 진행되는가
- [ ] 🔴 **이상하면 즉시 STABILIZE 로 탈취**

---

## 상시 감시 — 비행 내내

- **소리** — 갑자기 달라지면 착륙
- **자세** — 흔들리기 시작하면 착륙
- **배터리 전압** — 14.0 V 접근 시 착륙 준비
- **비행 시간** — 🔴 **첫 비행은 5분 이내로 끊는다**
- **기체 위치** — 시야를 벗어나지 않는다

---

## 착륙 후

- [ ] DISARM, 안전스위치 잠금
- [ ] 배터리 분리
- [ ] 🔴 모터·ESC·배터리 온도 확인
- [ ] 기체 육안 점검 — 나사 풀림, 프롭 손상, 균열
- [ ] 배터리 셀 전압 확인
- [ ] SD 카드 로그 회수 → `flights/` 에 저장
- [ ] **비행 기록 작성** → `flights/YYYY-MM-DD-<슬러그>.md`

## 로그에서 반드시 읽을 것

첫 비행 로그에서 아래를 뽑아 [계산서](../design/01-thrust-weight.md)를 갱신한다.

| 항목 | 로그 필드 | 왜 |
|---|---|---|
| 실제 호버 스로틀 | `CTUN.ThO` | `MOT_THST_HOVER` 갱신 |
| 호버 전류 | `BAT.Curr` | 비행시간 재계산 |
| 전압 새그 | `BAT.Volt` | failsafe 임계 검증 |
| 진동 | `VIBE.VibeX/Y/Z`, `Clip` | 방진 대책 판단 |
| EKF 상태 | `XKF*` | 센서 신뢰도 |
| 자세 추종 오차 | `ATT.DesRoll` vs `Roll` | PID 조정 필요성 |
| 나침반 오차 | `MAG`, `ERR` | 간섭 여부 |

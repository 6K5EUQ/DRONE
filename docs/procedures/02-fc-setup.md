## 🔴 A. 스택 결정 — 가장 먼저 답한다

실물 FC 에는 **ArduCopter V3.6.12** 가 올라가 있고, 캘리브레이션과 PID 가
이미 잡혀 있다. 이걸 살릴지 지울지부터 정한다.

| | A안: ArduCopter 유지 | B안: ArduCopter 최신화 | C안: PX4 전환 |
|---|---|---|---|
| 현재 설정 | ✅ 그대로 | 🔴 초기화됨 | 🔴 초기화됨 |
| 펌웨어 | V3.6.12 (2019) | 4.5.x (FMUv3 축소 빌드) | v1.14 (FMUv3 마지막) |
| `MOT_THST_HOVER` | ✅ 0.540 유지 | 🔴 재학습 | 🔴 재학습 |
| 버그·기능 | ⚠️ 구형 | ✅ 최신 | ✅ |
| SHADE01 도구 | 🔴 안 통함 | 🔴 안 통함 | ✅ 통함 |
| 작업량 | 최소 | 중간 | 최대 |

**권장: B안 (ArduCopter 최신화).**
- V3.6.12 는 2019년 펌웨어로 그동안 쌓인 안전 개선이 빠져 있다
- 어차피 프레임·프롭이 바뀌면 PID 와 호버추력은 다시 잡아야 한다
- PX4 는 FMUv3 지원이 v1.14 에서 끊겨, 최신성 이점이 없다
- ArduCopter 4.5.x 는 FMUv3 를 아직 지원한다 (일부 기능이 빠진 축소 빌드)

🔶 **단, SHADE01 과 스택을 통일하고 싶다면 C안.** 도구·감각의 재사용 가치가 크다.

## E. 캘리브레이션

순서를 지킨다. 앞 단계가 뒤 단계의 전제다.

- [ ] **가속도계** — 6면 전부. 평평한 곳에서, 기체를 흔들지 않고
- [ ] **자기계(나침반)** — 🔴 **야외에서.** 실내는 철근·전자기기 때문에 오염된다
  - [ ] 외장 자기계 우선 사용, 내장은 보조 또는 비활성
  - [ ] 오프셋이 비정상적으로 크면 GPS 마스트를 더 띄운다
- [ ] **RC 송신기** — 전 채널 min/max/trim
  - [ ] 이전 값 참고: MIN 982 / MAX 2005 / TRIM 1494 (로그 복원값)
- [ ] **ESC 스로틀 범위** — 🔴 **프롭 분리 상태에서** 4개 동시
- [ ] **전압·전류 센서** — 멀티미터 실측과 대조해 `BATT_VOLT_MULT`, `BATT_AMP_PERVLT` 보정
  - [ ] 이전 값: 10.8199 / 18.0018 — **PM 이 바뀌었으면 무효**

## F. 비행 모드 배치

이전 설정 (로그 복원값, `FLTMODE_CH=5`):

| 스위치 위치 | 모드 |
|---|---|
| 1 | LOITER (5) |
| 2, 3, 5, 6 | STABILIZE (0) |
| 4 | ALT_HOLD (2) |

⚠️ **초기 시험에는 STABILIZE 와 ALT_HOLD 만 쓴다.**
LOITER 는 GPS 와 자기계가 검증된 뒤에.

- [ ] 모드 배치 설정
- [ ] 🔴 **비상 정지(Emergency Stop) 또는 Motor Interlock 을 스위치에 할당**
- [ ] 송신기에서 실제로 모드가 바뀌는지 GCS 로 확인

## G. 🔴 배터리 Failsafe — 반드시 고친다

**현재 값은 잘못돼 있다.** 로그 8·9·10 에서 failsafe 가 계속 터져 시험이 중단됐다.

| 파라미터 | 현재(잘못) | 권장 | 근거 |
|---|---|---|---|
| `BATT_LOW_VOLT` | 🔴 14.4 V | **14.0 V** | 3.5 V/셀 — 부하 상태 4S |
| `BATT_CRT_VOLT` | 🔴 14.0 V | **13.2 V** | 3.3 V/셀 |
| `BATT_CAPACITY` | 2900 | 2900 | ✅ 보유 배터리와 일치 |
| `BATT_LOW_MAH` | — | **2030** | 용량의 70 % |
| `BATT_CRT_MAH` | — | **2320** | 용량의 80 % (DoD 상한) |
| `BATT_FS_LOW_ACT` | 2 (RTL) | 2 (RTL) | ✅ |
| `BATT_FS_CRT_ACT` | 1 (LAND) | 1 (LAND) | ✅ |

⚠️ low 와 critical 사이에 **최소 0.8 V 이상** 간격을 둔다.
현재는 0.4 V 라 사실상 동시에 터진다.

- [ ] 위 값으로 재설정
- [ ] [FC_CHANGELOG](../../FC_CHANGELOG.md) 기록

## H. 기타 안전 설정

| 파라미터 | 값 | 이유 |
|---|---|---|
| `ARMING_CHECK` | **1 (전체)** | 🔴 **절대 끄지 않는다** |
| `ANGLE_MAX` | **3000 (30°)** | ⚠️ 현재 4500(45°). 초기 시험에는 낮춘다 |
| `FS_THR_ENABLE` | 1 | RC 상실 시 동작 |
| `FS_CRASH_CHECK` | 1 | 충돌 감지 시 disarm |
| `FS_EKF_ACTION` | 1 | EKF 이상 시 동작 |
| `RTL_ALT` | 1500 (15 m) | 주변 장애물보다 높게. 현장에 맞춰 조정 |
| `BRD_SAFETYENABLE` | 1 | 안전스위치 필수 — 실물이 있어야 ARM 된다 |

- [ ] 위 값 확인·설정
- [ ] 🔴 **ESC 저전압 컷오프는 꺼져 있는가** — ESC 쪽 설정. 비행 중 모터가 꺼지면 추락한다

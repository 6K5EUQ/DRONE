# GT DRONE 3508-380KV — 모터

쿼드 4개용. 보유 중. 빨간 알루미늄 벨, 검은 스테이터 하우징에 `3508-380KV` 각인.

확인일 2026-09-14 (실물 사진).

---

## 🔶 브랜드 불명

각인은 `3508-380KV` 뿐이고 제조사 표기가 없다.
**T-Motor MN3508 정품이 아니다** — 정품은 금색/흑색 벨에 T-MOTOR 각인이 있다.
Turnigy Multistar, SunnySky, 또는 중국산 무명 클론 계열로 보인다.

→ 아래 사양은 **동급 T-Motor MN3508 KV380 데이터시트** 값이다.
**이 모터의 실측값이 아니다.** ±10~15 % 오차를 가정하고,
[지상 추력 시험](../../../docs/procedures/03-ground-test.md)으로 대체한다.

## 🔴 배선 — 회전 방향

3상 A/B/C 중 **아무 두 선을 바꾸면 역회전**한다.
쿼드 X 에서 Motor1·2 는 CCW, Motor3·4 는 CW.
→ [조립 절차 F 항](../../../docs/procedures/01-assembly.md)에서 방향을 확정하고 표시한다.

## 📋 확인해야 할 것

- [ ] 실물 중량 저울 실측 (4개 각각)
- [ ] 축경 실측 — 프롭 어댑터 규격이 여기 묶인다
- [ ] 마운트 홀 패턴 (대개 M3, 16 mm / 19 mm 피치) — 프레임 암과 맞는지
- [ ] 베어링 상태 — 손으로 돌려 걸림·소음 확인
- [ ] 4개 저항값이 서로 비슷한지 (권선 불량 선별)

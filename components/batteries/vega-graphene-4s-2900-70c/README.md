# VEGA GRAPHENE ULTIMATE LiPo — 4S 2900 mAh (DRONE01 배터리)

DRONE01 에 쓰는 배터리. 확인일 2026-10-12 (라벨 사진 1장 + 충전기 화면 사진 7장, 사진 원본은 저장소에 없음).

## 라벨 기재 사양 — ✅ 실물 확인 (2026-10-12 사진)

| 항목 | 값 |
|---|---|
| 제품 | **VEGA GRAPHENE — ULTIMATE LIPO** |
| 셀 수 | **4cell (4S)** |
| 공칭 전압 | **14.8 V** |
| 용량 | **2900 mAh** |
| 방전율 | **70C** (용량 옆 작은 표기) |

🔶 이 사진은 팩 **한 개**의 라벨이다. 충전기에는 팩 두 개가 꽂혀 있었고, 두 번째 팩의 라벨은 아직 못 봤다.

### 🟠 기존 문서와 충돌 — 방전율

| 문서 | 적힌 값 | 상태 |
|---|---|---|
| [README.md](../../../README.md) 16행, [설계 01](../../../docs/design/01-thrust-weight.md) 23·101·132·134행, 웹 부품 탭 | **4S 2900 mAh 20C**, 최대방전 20C × 2.9 A = 58 A | 🔶 **출처가 라벨이 아니다** (2026-09-14 보유 목록). 이번 라벨은 70C |
| 같은 문서들 | 6S 2900 mAh 70C 를 따로 보유 | 이번 라벨은 **4cell 14.8 V** 이다 — 6S 가 아니다 |

- 라벨이 70C 이므로, 70C 가 이 기체 4S 팩의 값일 가능성이 높다. 다만 **보유 팩이 두 종류(20C·70C)인지, 20C 가 오기인지** 는 확인 안 됐다.
- 70C 면 최대방전 70 × 2.9 = 203 A. 어느 쪽이든 이 기체의 최대 전류(로그 최대 17.6 A — 2026-10-07 로그 22)는 한참 아래라 **방전 한계가 병목이 아니다.**
- **2026-10-12 정정함** (사용자 지시): 위 문서들의 20C·58 A 는 지우지 않고 취소선으로 남기고 70C·203 A 로 바꿨다.
  README.md 16행, 설계 01 (23·101·132·134·150행), 웹 부품 탭 (`cockpit.js` 38행).
- 🔶 **일부러 안 바꾼 것 — 한계값으로 쓰는 58 A:** `web/extract.py` `CUR_BATT_A=58` (로그 차트의 전류 한계선),
  [절차 03](../../../docs/procedures/03-ground-test.md) 205행 「배터리 58 A 안에 드는가」.
  두 번째 팩이 20C 일 수 있어 안전한 쪽(58 A)을 그대로 둔다. 팩을 모두 확인하면 정한다.

## 충전기 화면 — ✅ 2026-10-12 사진 (충전 시작 직후 약 1분)

충전기: **HOTA 계열 듀얼 충전기** — AC 200 W / DC 650 W / 15 A (모델명은 앞부분이 가려져 「…6 Pro」 까지만 보임) 🔶
설정: LiPo-4S 4.20 V, 충전 전류 **약 3.0 A (≈ 1.0 C)**. 충전기 입력 29.2 V, 내부 온도 46 °C.

| | CH1 팩 | CH2 팩 |
|---|---|---|
| 충전 시작 팩 전압 | **15.57 V** | **14.64 V** |
| 셀 전압 (V) | 3.896 / 3.894 / 3.895 / 3.888 | 3.658 / 3.662 / 3.663 / 3.656 |
| 셀 편차 | 8 mV | 7 mV |
| 충전기가 표시한 잔량 | 55~56 % | 22~23 % |
| 내부저항 (mΩ, 1·2·3·4번 셀) | 7.2 / 5.8 / 2.8 / 2.4 (합 **18.2**) | 1.3 / 3.5 / 17 / 12 (합 **33.8**) |
| 사진 시점 충전량 | 30~40 mAh (48~61 초) | 41~49 mAh (60~70 초) |

- 셀 균형은 두 팩 모두 양호하다 (편차 10 mV 이내).
- 🔶 **내부저항은 신뢰하지 마라.** 충전 직후 순간 측정이고, 같은 팩의 이전 화면과 값이 다르게 나온다 (CH2: 1.3·3.5·17·12 가 한 화면, 같은 셀이 다른 화면에서는 다름). 재측정이 필요하다.
  - 그래도 CH2 는 한 셀이 두 자릿수(12~17 mΩ)로 나와 노화·불량 셀 의심 대상이다.
- 충전 **시작 전압**이 낮다: CH1 은 셀당 3.89 V, CH2 는 3.66 V — 만충 4.20 V 에 한참 못 미친다.

### 비행 로그와의 연결 (2026-10-07 받은 로그 19~22)

| | 시작 전압(셀당) |
|---|---|
| 로그 19·20·21·22 | 3.71 / 3.70 / 3.79 / 3.74 |
| 이번 사진 팩 | 3.89 / 3.66 |

- 팩을 **만충하지 않은 채** 비행하고 있다는 앞선 결론과 같은 범위다. 이 사진의 팩이 어느 로그의 팩인지는 알 수 없다.
- FC(ArduCopter 3.6)는 부팅할 때 무조건 100 % 로 시작한다. 그래서 만충이 아니면 웹의 배터리 % 가 실제보다 높게 나온다.

## 충전 완료 — 2026-10-12 (사용자가 옮겨 적은 충전기 화면 글자, 🔶 사진 글자 인식 결과라 오차 가능)

| | CH1 팩 | CH2 팩 |
|---|---|---|
| 충전 전 셀 전압 (위 표) | 3.89 V | 3.66 V |
| **충전기가 넣은 양** | **921 mAh** (25분 10초) | **2002 mAh** (46분 32초) |
| 충전 후 셀 전압 | 4.190~4.193 V (편차 3 mV) | 4.201~4.204 V |
| 상태 | 100 % 충전 완료, 16.77 V | 충전 완료, 16.8 V |
| 내부저항 (1·2·3·4번 셀) | 5.1 / 4.7 / 4.6 / 6.0 mΩ (합 ≈ 20) | 이번 화면에 없음 |
| 충전 에너지 | 15.1 Wh | – |

- CH1 의 내부저항은 이전 측정(7.2/5.8/2.8/2.4, 합 18)과 셀별 값은 달라도 **합은 비슷**하고 셀 간 고르다. 정상 범위로 본다.
- 🔶 CH2 팩의 17 mΩ 셀은 이번에 다시 못 쟀다.

### 이 팩의 전압–잔량 기준점 (🔶 충전기가 넣은 mAh ÷ 2900 으로 환산, 2점)

| 셀당 휴지 전압 | 잔량 |
|---|---|
| 3.66 V | **약 31 %** (2002 mAh 충전) |
| 3.89 V | **약 68 %** (921 mAh 충전) |
| 4.19 V | 100 % |

- 팩 용량이 정확히 2900 mAh 이고 이전에 만충이었다는 가정이다. 팩이 노화돼 용량이 작았다면 잔량은 더 낮다.
- 🟠 **정정:** 앞서 일반 LiPo 표로 계산한 「로그 19~22 시작 잔량 9~34 %, 끝 5~10 %, 거의 빈 상태로 날았다」는 **과장이었다.**
  이 팩의 기준점으로 다시 보면 시작은 약 37~52 %, 끝은 약 23~36 % 다 (로그 17 은 시작 82 % → 끝 38 %).
  특히 3.66 V 부근에서 일반 표(약 8 %)와 크게 달랐다. 여전히 **만충이 아닌 채 비행**한 것은 맞다.
- 이 기준점으로 본 전압 기준 소모량 대비 FC 가 기록한 소모량: 로그 17 은 1269 : 441 mAh (**약 2.9배**).
  앞선 추정(4.3배)보다 작다. 🔶 전류 센서가 낮게 읽는 방향은 같다.
- 충전기 합계(2923 mAh)와 로그 17~22 의 FC 기록 합계(663 mAh)는 4.4배 차이지만, 그 팩들이 로그 17 이전에 만충이었는지,
  그 사이 다른 사용이 없었는지 알 수 없어서 **보정값으로 쓰지 않는다.**

## 아직 모르는 것 (🔶)

- 두 번째 팩의 라벨 (모델·방전율 동일한지)
- **풀충전까지 들어간 mAh** — 이번 사진은 충전 시작 1분이라 쓸 수 없다. 전류 센서 보정(`BATT_AMP_PERVLT`)에 필요한 값은 다음 순서로 얻는다:
  1. 만충 → 2. 한 번 부팅한 채 비행(중간에 FC 전원 끄지 않음) → 3. 로그의 소모 mAh 확인 → 4. 같은 팩을 재충전하며 충전기가 보여 주는 최종 mAh
- 팩 구입일·사이클 수·노화 상태
- 이 팩의 실제 전압-잔량 곡선 (지금은 일반 LiPo 곡선으로 추정)

쿼드 4개용. 보유 중. 확인일 2026-09-14 (실물 라벨 사진).

## 라벨 기재 사양 — ✅ 실물 확인

| 항목 | 값 |
|---|---|
| 제품명 | GT DRONE **EC-X3 MultiRotor** |
| 종류 | BLDC Speed Controller |
| 🔴 **BEC** | **없음 (OPTO ESC, No BEC)** |
| 연속 전류 | **30 A** |

---

## 🔴 No BEC — 설계에 영향을 준다

이 ESC 는 **5 V 를 만들지 않는다.** OPTO 는 신호선이 광절연(또는 상응 절연)되어
있고 BEC 회로가 빠진 구조다. 따라서:

- FC, GPS, 수신기, 부저, 안전스위치의 **5 V 를 다른 데서 받아야 한다**
- 공급원 후보: **전원모듈(PM)** 의 5 V 출력, 또는 **별도 UBEC**
- Pixhawk 2.4.8 표준 세트의 PM 은 대개 **5.3 V / 2.25 A** 급

⚠️ PM 5 V 로 FC + GPS + 수신기까지는 보통 충분하다.
짐벌·서보·LED 를 추가하면 모자란다 → 그때는 별도 UBEC 를 단다.

🔴 **PM 실물이 있는지 확인이 안 됐다.** → [조립 절차 D 항](../../../docs/procedures/01-assembly.md)

## 🔶 미확인 — 실물로 확인해야 하는 것

라벨에 적히지 않은 것들. ESC 성능과 셋업이 여기 달렸다.

| 항목 | 왜 중요한가 | 확인 방법 |
|---|---|---|
| **펌웨어** (BLHeli / BLHeli_S / SimonK / 독자) | 프로토콜·설정 가능 범위가 갈린다 | BLHeliSuite 로 연결 시도 |
| **지원 프로토콜** (PWM / OneShot / DShot) | FC 출력 설정이 달라진다 | 펌웨어에 종속 |
| **최대 갱신율** | 제어 반응성 | 펌웨어에 종속 |
| **저전압 컷오프 기본값** | 🔴 **비행 중 모터가 꺼질 수 있다** | 반드시 확인·해제 |
| **타이밍 설정** | 3508 같은 저KV 대형 모터는 타이밍이 중요 | BLHeliSuite |
| 실물 중량 | 중량 예산 | 저울 |
| 입출력 선 규격 | 전류 용량 | 육안 (AWG) |

🔴 **ESC 저전압 컷오프는 반드시 끄거나 최저로 낮춘다.**
배터리 보호는 **FC 의 failsafe** 가 담당해야 한다.
ESC 가 독자적으로 모터를 끄면 비행 중 추락한다.

## FC 파라미터와의 관계

로그에서 복원한 현재 FC 설정
([FC 문서](../../fc/pixhawk-2.4.8/README.md) 참조):

| 파라미터 | 값 | 의미 |
|---|---|---|
| `MOT_PWM_TYPE` | 0 | **일반 PWM** — DShot 미사용 |
| `RC_SPEED` | 490 Hz | ESC 갱신율 |
| `MOT_PWM_MIN` / `MAX` | 1000 / 2000 | 펄스폭 범위 |

→ 지금은 **PWM 490 Hz** 로 돌고 있다. ESC 가 DShot 을 지원한다면
전환을 검토할 수 있으나, **일반 PWM 으로도 멀티로터에 충분하다.**
펌웨어 확인 전에는 건드리지 않는다.

---

## 전류 여유 — ✅ 넉넉하다

[계산서](../../../docs/design/01-thrust-weight.md) 기준, 4S + 14×4.8 풀스로틀에서
**모터당 6.3 A**. ESC 30 A 정격의 **21 %** 다. 과분하게 여유롭다.

6S 풀스로틀도 모터당 14~17 A 로 ESC 안에는 들지만,
**모터 정격을 먼저 넘기 때문에** 6S 는 쓰지 않는다 (계산서 §4).

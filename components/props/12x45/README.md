## 🔶 실측 안 됨

사이즈 12인치·피치 4.5는 사용자가 확인한 값이다.
재질·정확한 표기(CF/PC/균형 여부)·실물 중량은 **아직 확인하지 않았다.**

→ 아래 추력·효율 값은 [설계 계산 01](../../../docs/design/01-thrust-weight.md)의
**추정치**(T-Motor MN3508 KV380 실측표 기반 보간)이며, 이 프롭 실물의 실측이 아니다.
[지상 추력 시험](../../../docs/procedures/03-ground-test.md)으로 대체한다.
